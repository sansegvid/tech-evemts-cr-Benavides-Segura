## Descripción

TechEvents CR es una página web que muestra eventos de tecnología en Costa Rica. Cada evento aparece en una tarjeta con su fecha, modalidad y cupos disponibles. El usuario puede inscribirse con el botón de cada tarjeta, y los cupos bajan hasta que el botón cambia a "Agotado". También hay una sección de inscripción rápida que calcula los cupos restantes.

El trabajo incluye un ejercicio de debugging con tres errores intencionales, que se encontraron y corrigieron con las herramientas del navegador. El proceso está documentado en [DEBUG.md](DEBUG.md) y las capturas están en la carpeta [evidencias](evidencias/).
